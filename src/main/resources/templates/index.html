DBApp

En enkel app for å hente data fra databaser med SQL.

ℹ️ Om DBApp

Hva er DBApp?

DBApp er et SQL-grensesnitt for undervisning: studentene skriver SQL-spørringer mot flere databasesystemer (PostgreSQL, Microsoft SQL, Oracle, MySQL og SQLite) og får resultatet umiddelbart — uten side-reload.

Funksjoner

SQL-faner, mørkt/lyst tema, norsk/engelsk språk, autocomplete med Tab, tastatursnarveier og per-bruker SQLite-databaser.

Teknologier brukt:
  • Java SE
  • Spring Boot
  • Bootstrap
  • CodeMirror 6
  • sql-formatter

Prosjektet er åpent — kildekoden ligger på GitHub under MIT-lisens.
